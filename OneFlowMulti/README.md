# OneFlowMulti 🧭
**Author:** [althea89sky](https://github.com/althea89sky)  
**License:** MIT

## Overview
OneFlowMulti distributes ETH and ERC-20 tokens across 5 configurable wallets based on settable percentage rates. Use it for team treasury splits, royalty payments, or protocol fees.

## Features
- 5 wallet addresses
- Independent rate settings per wallet (basis points)
- Auto ETH distribution
- Manual ERC-20 token split
- Deployable on all EVM chains
