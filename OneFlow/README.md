# OneFlow 🌀
**Author:** [althea89sky](https://github.com/althea89sky)  
**License:** MIT

## Overview
OneFlow is a minimalist smart contract that auto-forwards a configurable percentage of incoming ETH and ERC-20 tokens to a single wallet. Designed for transparent fee routing, treasury streaming, or royalty collection.

## Features
- Set a single payout address
- Define a flow rate (e.g. 7500 = 75%)
- Auto-distributes native tokens (ETH, BNB, MATIC, etc.)
- Manual ERC-20 token distribution
- Deployable to all EVM-compatible chains
