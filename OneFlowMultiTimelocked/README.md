# OneFlowMultiTimelocked ⏳
**Author:** [althea89sky](https://github.com/althea89sky)  
**License:** MIT

## Overview
OneFlowMultiTimelocked distributes ETH and ERC-20 tokens to 5 wallets based on rates, with a configurable time lock to control distribution frequency.

## Features
- 5 wallet addresses with independent rate settings
- Time lock enforcement between distributions
- Works on all EVM-compatible chains
- Secure and owner-controlled
